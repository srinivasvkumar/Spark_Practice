# Streaming Aggregations in PySpark

## Overview
Streaming aggregation allows real-time computations on continuously incoming data. PySpark provides powerful tools for performing such aggregations efficiently.

## Performing Streaming Aggregations
We perform a **windowed count aggregation** to count the number of events within time windows.

```python
from pyspark.sql import SparkSession
from pyspark.sql.functions import window, count, col
from pyspark.sql.types import StructType, StructField, StringType, TimestampType

# Initialize Spark Session
spark = SparkSession.builder.appName("StreamingAggregations").getOrCreate()

# Define schema for incoming data
df_schema = StructType([
    StructField("timestamp", TimestampType(), True),
    StructField("event", StringType(), True)
])

# Read streaming data from a source (Example: Socket)
streaming_df = spark.readStream.format("socket").option("host", "localhost").option("port", 9999).load()

# Parse incoming data
parsed_df = streaming_df.selectExpr("CAST(value AS STRING)").selectExpr(
    "split(value, ',')[0] AS timestamp",
    "split(value, ',')[1] AS event"
).withColumn("timestamp", col("timestamp").cast(TimestampType()))

# Perform aggregation
aggregated_df = parsed_df.groupBy(
    window("timestamp", "10 minutes"),  # 10-minute time window
    "event"
).agg(count("event").alias("event_count"))

# Write the aggregation results to console
query = aggregated_df.writeStream.outputMode("complete").format("console").start()

query.awaitTermination()
```

## Explanation
- **Windowed Aggregation**: Groups data into 10-minute intervals and counts events.
- **Streaming Source**: Reads real-time data from a socket.
- **Output Mode**: Uses `complete` mode to update results continuously.

This setup can be extended to integrate with sources like Kafka or file-based streaming sources.
